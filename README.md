# Лабораторная работа WT-6 - Minimal API (Доставка еды)

## API Методы
| Метод | URL | Назначение |
|---|---|---|
| GET | /api/dishes | Получить список блюд (с поиском) |
| GET | /api/dishes/{id} | Получить блюдо по ID |
| POST | /api/dishes | Создать блюдо |
| PUT | /api/dishes/{id} | Изменить блюдо |
| DELETE | /api/dishes/{id} | Удалить блюдо |
| GET | /api/orders | Получить список заказов |
